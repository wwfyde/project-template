## Anatomy

组件直接从 `@base-ui/react` package 导入。下面保留组件结构和完整 API，作为维护自己组件文档的参考：

```jsx title="Anatomy"
import { Accordion } from '@base-ui/react/accordion';

<Accordion.Root>
  <Accordion.Item>
    <Accordion.Header>
      <Accordion.Trigger />
    </Accordion.Header>
    <Accordion.Panel />
  </Accordion.Item>
</Accordion.Root>;
```
