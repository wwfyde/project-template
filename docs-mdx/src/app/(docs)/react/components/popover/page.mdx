## Anatomy

组件直接从 `@base-ui/react` package 导入。下面保留组件结构和完整 API，作为维护自己组件文档的参考：

```jsx title="Anatomy"
import { Popover } from '@base-ui/react/popover';

<Popover.Root>
  <Popover.Trigger />
  <Popover.Portal>
    <Popover.Backdrop />
    <Popover.Positioner>
      <Popover.Popup>
        <Popover.Arrow />
        <Popover.Viewport>
          <Popover.Title />
          <Popover.Description />
          <Popover.Close />
        </Popover.Viewport>
      </Popover.Popup>
    </Popover.Positioner>
  </Popover.Portal>
</Popover.Root>;
```

### Viewport

<TypesPopover.Viewport />

`Viewport` 是可选的，适用于多个触发器打开同一个浮层、内容随触发器变化且需要切换动画的场景。使用时，为 `Positioner` 设置 `width: var(--positioner-width)` 和 `height: var(--positioner-height)`，在过渡期间保持测量后的尺寸，避免内容变化造成浮层抖动或切换定位方向。
