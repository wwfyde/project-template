# 用户、租户、账户与内容

本上下文区分登录身份、计费归属、资源账户、文件载体和业务内容。同一用户可以加入多个账户，同一份内容可以被不同业务对象引用。

## Language

**User（用户）**：
系统中的登录身份，具有稳定用户标识、登录名及可修改的个人资料。
_Avoid_：把用户身份与资源归属账户混为一谈。

**UID（用户数字身份）**：
用户首次保存时分配的唯一数字编号，后续修改资料或用户名不会改变它。
_Avoid_：用尚未分配的零值表示已存在用户，或把 UID 当成可编辑资料。

**Tenant（租户）**：
组织和计费归属单元，分为个人租户与组织租户；组织租户可以包含多个资源账户。
_Avoid_：把租户成员资格等同于其所有工作空间的访问权。

**Account（账户）**：
资源的管理与隔离边界，属于一个租户；账户类别为个人账户或工作空间。
_Avoid_：把账户当作登录身份或第三方登录凭证。

**Personal Account（个人账户）**：
用户默认拥有的个人资源空间，归属该用户的个人租户，不与其他用户共享。
_Avoid_：把个人账户当作多人工作空间。

**Workspace（工作空间）**：
组织租户下可由多名成员共同管理的账户类别；同一组织内的不同工作空间仍相互隔离。
_Avoid_：把工作空间当作独立计费租户，或再为它创建另一种账户身份。

**Membership（成员关系）**：
用户在某个租户或账户中的参与关系及角色；租户成员与账户成员分别表达。
_Avoid_：把一个用户的全局角色用于所有组织和工作空间。

**Owner / Admin / Member（所有者／管理员／成员）**：
成员在当前租户或账户中的权限角色；所有者管理角色，管理员管理普通成员，普通成员使用其已获准访问的资源。
_Avoid_：把组织所有者解释成自动拥有每个工作空间的资源访问权。

**File（文件）**：
一份具有稳定身份的字节内容；内容改变后是一份新文件。
_Avoid_：用资产、文档或知识条目统称所有文件。

**Media Kind（文件内容大类）**：
文件内容的粗粒度类别，例如图片、文档、音频和视频，与业务用途分别表达。
_Avoid_：把图片、资产和知识库放在同一个类型分类中。

**Asset（资产）**：
可复用的业务资源，例如 Logo、照片、插画、模板或品牌规范；一项资产可以拥有原稿、预览和导出文件。
_Avoid_：以 Design 或 Creative 统称所有资产。

**File Role（文件作用）**：
文件在某项资产中的用途，例如原稿、缩略图、导出图或蒙版；同一个文件可以承担不同作用。
_Avoid_：把作用当成文件格式或固定的库归属。

**Document（文档）**：
具有稳定业务身份和修订历史的内容，可以来自在线正文，也可以由上传文件承载。
_Avoid_：把所有 PDF 文件或知识来源自动视为文档库文档。

**Document Revision（文档修订）**：
文档在某一版本的确定内容，历史引用指向该版本。
_Avoid_：以始终变化的当前正文代表历史版本。

**Knowledge Base（知识库）**：
一组被收录并用于检索的知识来源，具有自己的访问边界。
_Avoid_：把知识库等同于向量存储。

**Knowledge Source（知识来源）**：
可追溯到一份确定文件或文档修订的内容快照，同一来源可以被多个知识库收录。
_Avoid_：把临时下载链接或向量本身当作来源。

**Knowledge Base Source（知识库收录）**：
知识库与某个来源之间的收录关系，其索引进度和移除状态属于该关系。
_Avoid_：以删除原件表示从某个知识库移除。

**Knowledge Chunk（知识片段）**：
用于检索和引用的来源片段，同时保留内容和原文位置。
_Avoid_：仅用相似度或嵌入向量充当引用证据。

**Source Locator（来源定位）**：
来源内的具体位置，例如 PDF 页码、文本区间、图片区域或音视频时间区间。
_Avoid_：把回答中的标注位置当成原文件页码。

**Design（设计工程）**：
具有画布、图层或组件等编辑结构的设计内容；普通设计素材仍可作为资产管理。
_Avoid_：用设计工程代替所有可复用资产。

**Creative（广告创意）**：
面向广告表达或投放的创意内容，可能包含文案、渠道和尺寸变体。
_Avoid_：用广告创意统称所有图片、文档和资产。
